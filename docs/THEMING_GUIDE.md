# SonicFlow — Руководство по темам (Theming Guide)

Документ описывает архитектуру тем оформления, работу CSS Custom Properties, процесс применения стилей, доступность и формат импорта/экспорта.

## 1. Архитектура тем

В SonicFlow тематизация реализована исключительно через нативные **CSS Custom Properties** (CSS-переменные), без runtime CSS-in-JS пересчетов, что гарантирует мгновенное переключение (60 FPS) без дерганий и без прерывания аудиопотока.

### Список семантических токенов темы:

| Токен | Описание | Пример значения |
|---|---|---|
| `--color-bg-base` | Корневой фон экрана | `#0b0b0e` |
| `--color-bg-sidebar` | Фон бокового меню и навигации | `#101014` |
| `--color-bg-surface` | Карточки треков и плейлистов | `#18181e` |
| `--color-bg-surface-hover` | Наведение курсора на карточку | `#24242d` |
| `--color-bg-player` | Фон панели проигрывателя | `#121217` |
| `--color-text-primary` | Основной текст и заголовки | `#f6f6f8` |
| `--color-text-secondary` | Имена исполнителей, описания | `#a4a4b0` |
| `--color-text-muted` | Неактивные иконки, плейсхолдеры | `#777784` |
| `--color-accent` | Главный фирменный акцентный цвет | `#ff5500` |
| `--color-accent-hover` | Состояние hover для акцента | `#ff7133` |
| `--color-accent-contrast`| Текст поверх акцентного цвета | `#ffffff` |
| `--color-border` | Тонкие разделители и рамки | `rgba(255, 255, 255, 0.08)` |
| `--color-lyrics-active` | Активная строка текста песни | `#ffffff` |
| `--color-lyrics-inactive`| Неактивные строки текста | `#777783` |
| `--radius-card` | Скругление карточек альбомов | `16px` |
| `--radius-control` | Скругление кнопок и инпутов | `10px` |

## 2. Встроенные темы оформления (Presets)

Приложение поставляется с 9 тщательно откалиброванными пресетами:

1. **Midnight Black (Тёмная студия)** — глубокий темный фон `#0b0b0e` с нейтральными графитовыми поверхностями и ультрамариновым акцентом `#3b82f6`.
2. **SoundCloud Orange (Фирменная)** — оригинальная палитра SoundCloud с ярким оранжевым акцентом `#ff5500` на теплом темно-сером фоне `#121212`.
3. **Spotify Green (Неоновый изумруд)** — культовая эстетика Spotify: глубокий черный `#121212` и неоновый зеленый `#1db954`.
4. **Ocean Blue (Морская глубина)** — сапфировый темный фон `#08111e`, сине-стальные карточки и лазурный акцент `#35a7ff`.
5. **Violet Dream (Фиолетовый закат)** — ночной аметистовый фон `#0f0a1c` с сияющим фиолетовым акцентом `#a855f7`.
6. **AMOLED Pure Black (Абсолютный черный)** — истинный `#000000` для максимального энергосбережения OLED-экранов с контрастными белыми акцентами.
7. **Light Minimal (Светлый минимализм)** — кремовый благородный фон `#f4f3ef` с черным текстом и строгой журнальной типографикой (вдохновлен референсом мобильного плеера).
8. **Rose Neon (Киберпанк)** — глубокий сланцевый фон `#110b14` с акцентным неоновым розовым `#f43f5e`.
9. **Custom Theme (Пользовательская)** — динамическая тема, значения которой настраиваются в визуальном редакторе.

## 3. Механизм переключения темы (ThemeManager)

Процесс переключения:
1. Пользователь выбирает пресет в настройках или редактирует параметры в `ThemeEditor`.
2. `ThemeManager.setTheme(themeId, customTokens?)` валидирует идентификатор и структуру.
3. Устанавливается атрибут `document.documentElement.setAttribute('data-theme', themeId)`.
4. Если тема пользовательская, то кастомные токены инжектируются напрямую в `document.documentElement.style.setProperty('--token', value)`.
5. Текущая конфигурация сериализуется и сохраняется в `localStorage['sonicflow_theme']`.
6. При перезапуске приложения сохраненная тема восстанавливается до первого рендера компонентов, исключая белую вспышку (FOUC).

## 4. Спецификация JSON для импорта и экспорта

Пользовательские темы можно экспортировать в файл `.json` и делиться ими с другими пользователями.

### Схема формата (Version 1):
```json
{
  "$schema": "https://sonicflow.app/schemas/theme-v1.json",
  "schemaVersion": 1,
  "id": "neon-cyber",
  "name": "Neon Cyber",
  "author": "SonicFlow User",
  "colorScheme": "dark",
  "tokens": {
    "color-bg-base": "#0a0612",
    "color-bg-sidebar": "#0f091a",
    "color-bg-surface": "#181028",
    "color-bg-surface-hover": "#251a3d",
    "color-bg-player": "#120b20",
    "color-text-primary": "#f8f0ff",
    "color-text-secondary": "#b4a3cb",
    "color-text-muted": "#75668b",
    "color-accent": "#d946ef",
    "color-accent-hover": "#e879f9",
    "color-accent-contrast": "#ffffff",
    "color-border": "rgba(217, 70, 239, 0.15)",
    "color-lyrics-active": "#fdf4ff",
    "color-lyrics-inactive": "#6b5980",
    "radius-card": "16px",
    "radius-control": "10px"
  }
}
```

### Валидация при импорте:
- Проверка наличия обязательных полей `schemaVersion`, `id`, `name`, `tokens`.
- Проверка форматов цветов (HEX `#rrggbb`, `#rrggbbaa` или безопасный `rgba()`).
- Запрет на внедрение опасных CSS-инъекций (`javascript:`, `expression()`, `@import`).
- Ограничение размера импортируемого JSON файла до 64 КБ.

## 5. Доступность (Accessibility & WCAG 2.2 AA)

1. **Расчет коэффициента контрастности**:
   Тематический движок вычисляет относительную яркость цветов по формуле WCAG:
   $$L = 0.2126 \cdot R_{lin} + 0.7152 \cdot G_{lin} + 0.0722 \cdot B_{lin}$$
   Контраст рассчитывается как:
   $$\text{Ratio} = \frac{L_1 + 0.05}{L_2 + 0.05}$$
2. В редакторе тем отображается индикатор:
   - Зеленый бейдж **"WCAG AA PASS (5.2:1)"** при контрасте $\ge 4.5:1$.
   - Предупреждающий бейдж **"LOW CONTRAST (< 4.5:1)"**, если текст трудно читаем.
3. Поддержка системного режима `prefers-reduced-motion`: при активации в ОС длительность переходов автоматически уменьшается до `0.01ms`.
