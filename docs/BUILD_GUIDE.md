# SonicFlow — Руководство по сборке и запуску (Cross-Platform Delivery)

Документ описывает запуск и сборку полнофункционального плеера SonicFlow для **Windows**, **Linux** и **iOS** с поддержкой аккаунта **SoundCloud**.

---

## 1. Запуск и сборка на Windows

### Готовый запускаемый EXE-файл (уже скомпилирован):
- **`SonicFlow.exe`** находится прямо в корне проекта: `c:\Users\roki\Desktop\Soundcloud player\SonicFlow.exe`.
- **Ярлык на рабочем столе**: `C:\Users\roki\Desktop\SonicFlow.lnk` (с иконкой приложения).
- Двойной клик по ярлыку или `SonicFlow.exe` запускает плеер в изолированном окне нативного приложения (без браузерных рамок, с аппаратным ускорением и выводом звука).

### Пересборка EXE из исходников (C# + Vite):
```powershell
npm run build:exe
```
Команда собирает фронтенд-бандл через Vite и компилирует C# лаунчер встроенным компилятором `.NET Framework` (`csc.exe`) с иконкой `app.ico`. Дополнительных SDK устанавливать не требуется.

---

## 2. Запуск на Linux

### Готовый лаунчер:
- **`sonicflow-linux.sh`** — скрипт запуска для Ubuntu, Debian, Fedora, Arch, Manjaro и других дистрибутивов.
- **`SonicFlow.desktop`** — файл интеграции с главным меню приложений Linux (GNOME, KDE Plasma, XFCE).

### Быстрый запуск в Linux:
```bash
chmod +x sonicflow-linux.sh
./sonicflow-linux.sh
```
Скрипт автоматически поднимает локальный сервер и открывает приложение в оконном режиме через Chromium / Chrome / Brave / Firefox.

---

## 3. Сборка и запуск на iOS (iPhone / iPad)

### Способ А: Нативное приложение через Xcode (Capacitor)
Проект нативного iOS приложения уже инициализирован в каталоге `ios/`:
- Файл рабочей области: `ios/App/App.xcworkspace`.
- В `ios/App/App/Info.plist` уже сконфигурирован `UIBackgroundModes = audio` (фоновое воспроизведение при заблокированном экране и при сворачивании приложения).

Шаги сборки:
```bash
# 1. Синхронизация изменений веб-бандла в проект iOS
npm run build
npx cap sync ios

# 2. Открытие в Xcode (на macOS)
npx cap open ios
```
В Xcode выберите ваше устройство (или симулятор iPhone 15/16 Pro), укажите ваш Apple ID в `Signing & Capabilities` и нажмите **Run** (или экспортируйте `.ipa` / TestFlight).

### Способ Б: Установка как PWA (без Mac и Xcode)
В `index.html` и `public/manifest.json` настроены все мобильные теги Apple:
1. Запустите плеер локально или разместите на любом хостинге (Vercel, Cloudflare Pages, Netlify).
2. Откройте ссылку в **Safari** на iPhone.
3. Нажмите кнопку «Поделиться» (иконка со стрелочкой) → **«На экран «Домой»» (Add to Home Screen)**.
4. SonicFlow появится на рабочем столе iOS как нативное полноэкранное приложение с поддержкой фонового звука через MediaSession API.

## 4. Подключение и синхронизация аккаунта SoundCloud (в 1 клик)

1. Откройте SonicFlow (через ярлык на рабочем столе или `SonicFlow.exe`).
2. В левой боковой панели нажмите большую кнопку **«SoundCloud (1 клик)»**.
3. Нажмите **«Войти через SoundCloud (1 клик)»**:
   - SonicFlow автоматически свяжется с официальным шлюзом авторизации и откроет окно входа SoundCloud.
   - Войдите в свой аккаунт и нажмите «Разрешить» (Connect / Authorize).
4. SonicFlow в фоне мгновенно перехватит сессию, подключит аккаунт и запустит полную синхронизацию!
5. Для ручной повторной синхронизации достаточно нажать кнопку с иконкой обновления прямо в боковой панели рядом с вашим аватаром.

### Что синхронизируется в реальном времени:
- **Мои лайки**: ваши любимые треки с SoundCloud отображаются во вкладке *Favorites* / *Likes*.
- **Моя лента (Stream)**: новые релизы артистов, на которых вы подписаны.
- **Плейлисты**: ваши альбомы и подборки с soundcloud.com отображаются в *Playlists*.
- **Двусторонняя синхронизация лайков**: клик по сердечку у любого трека в SonicFlow ставит или удаляет лайк напрямую в вашем аккаунте на `soundcloud.com`.
- **Поиск**: глобальный поиск по миллионам треков SoundCloud.
