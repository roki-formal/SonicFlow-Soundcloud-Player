# SonicFlow — Система текстов песен (Lyrics System)

Документ описывает реализацию синхронизированных текстов песен, работу парсера LRC-файлов, интеграцию с провайдерами текстов и интерактивное поведение.

---

## 1. Концепция и референсы

Интерфейс текстов песен SonicFlow спроектирован на основе лучших практик **Spotify** и **Яндекс Музыки**:
- Кинетическая типографика: активная строка выделяется максимальным контрастом и увеличенным кеглем, предыдущие и последующие строки мягко приглушены.
- 4 вкладки в шапке (в точном соответствии с референсом 2):
  1. `Karaoke` — акцентированное караоке с пословной индикацией.
  2. `• Synced` (по умолчанию) — синхронизированная прокрутка строк.
  3. `Unsynced` — статичный текст для спокойного чтения.
  4. `Genius` — смысловые комментарии и факты о треке.
- Атрибуция источника текста внизу слева: `"Provided by Netease / LRCLIB / Local LRC"`.

---

## 2. Парсер формата LRC (`LrcParser`)

Парсер поддерживает стандартные и расширенные временные метки:
- Стандартная строка: `[mm:ss.xx] Текст строки`
- Расширенная строка: `[mm:ss.xxx] Текст строки`
- Мульти-таймкоды: `[00:12.50][01:34.20] Повторяющийся припев`
- Метатеги: `[ti:Название]`, `[ar:Артист]`, `[al:Альбом]`, `[by:Автор]`

### Алгоритм бинарного поиска активной строки:

Поскольку массив разобранных строк `LyricLine[]` отсортирован по возрастанию времени `timeSeconds`:

```typescript
export function findActiveLyricIndex(lyrics: LyricLine[], currentTime: number): number {
  if (!lyrics.length || currentTime < lyrics[0].time) return -1;
  let low = 0;
  let high = lyrics.length - 1;
  let best = 0;

  while (low <= high) {
    const mid = Math.floor((low + high) / 2);
    if (lyrics[mid].time <= currentTime) {
      best = mid;
      low = mid + 1;
    } else {
      high = mid - 1;
    }
  }
  return best;
}
```
Сложность поиска составляет $O(\log N)$, что исключает нагрузку на CPU даже при обновлении состояния 60 раз в секунду.

## 3. Интерактивные возможности

1. **Клик по строке (Click-to-Seek)**:
   При клике на любую строку с таймкодом `AudioEngine.seek(line.time)` немедленно перематывает трек на эту позицию.
2. **Умный автоскролл**:
   - Контейнер автоматически плавно прокручивает активную строку к центру области видимости.
   - Если пользователь начинает скроллить текст колесиком мыши или пальцем, автоматическая прокрутка блокируется на 4 секунды (или до нажатия кнопки "Следовать за музыкой"), предотвращая дергание страницы.
3. **Локальный импорт LRC и TXT**:
   - Пользователь может нажать кнопку "Импорт текста" или перетащить `.lrc`/`.txt` файл на экран плеера.
   - Файл мгновенно парсится локально и сохраняется в кэш IndexedDB для данного трека без отправки на сервер.
