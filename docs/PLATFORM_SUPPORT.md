# SonicFlow — Поддержка платформ (Platform Support)

Документ описывает особенности сборки и функционирования приложения на Windows, Linux и iOS.

---

## 1. Windows Desktop

- **Среда выполнения**: Поддержка Windows 10 (1809+) и Windows 11.
- **Интеграция с ОС**:
  - `MediaSession API`: отображение информации о текущем треке в оверлее Windows Volume Flyout и виджете медиаплеера на панели задач / Win+G.
  - Поддержка мультимедийных клавиш клавиатуры (Play/Pause, Next Track, Prev Track).
  - Сворачивание в трей и плавное закрытие без зависания фоновых аудиопроцессов.
- **Формат дистрибутива**: `.exe` установщик (NSIS) или портативный архив.

---

## 2. Linux Desktop

- **Среда выполнения**: Ubuntu/Debian, Fedora, Arch Linux и другие дистрибутивы с поддержкой X11 и Wayland.
- **Интеграция с ОС**:
  - Поддержка MPRIS2 через браузерную интеграцию MediaSession API.
  - Корректная поддержка дробного масштабирования и HiDPI-мониторов.
- **Форматы дистрибутивов**: `.AppImage` (автономный исполняемый файл) и `.deb` пакет.

---

## 3. iOS (iPhone)

- **Мобильная адаптация**:
  - Точное соответствие дизайну из референса 3: верхний остров Dynamic Island, крупный виниловый диск по центру, закругленная док-панель управления.
  - Нижняя шторка синхронизированных текстов песен с жестом смахивания (Swipe Down to dismiss).
  - Учет системных отступов `env(safe-area-inset-top)` и `env(safe-area-inset-bottom)`.
  - Управление одной рукой (все интерактивные элементы в зоне досягаемости большого пальца).
- **Сборка через Capacitor**:
  - Проект сконфигурирован с `@capacitor/core`, `@capacitor/cli` и `@capacitor/ios`.
  - Нативный проект Xcode генерируется командой `npx cap add ios` и синхронизируется через `npx cap sync`.
  - Фоновое воспроизведение настраивается в `Info.plist` с включением ключа `UIBackgroundModes: ["audio"]`.
  - Примечание: Для компиляции `.ipa` и установки на физическое устройство требуется среда macOS с установленным Xcode и учетной записью Apple Developer.
