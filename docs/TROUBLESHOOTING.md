# SonicFlow — Устранение неполадок (Troubleshooting Guide)

Документ содержит решения типичных проблем, возникающих при разработке, сборке и воспроизведении звука.

---

## 1. Проблемы с воспроизведением аудио

### Симптом: Звук не воспроизводится после нажатия Play
- **Причина 1 (Autoplay Policy)**: Браузеры блокируют автоматический запуск аудио без предварительного взаимодействия пользователя со страницей.
  - *Решение*: Первое воспроизведение должно инициироваться явным кликом пользователя по кнопке Play.
- **Причина 2 (CORS / Сетевая ошибка)**: Внешний сервер потока заблокировал запрос.
  - *Решение*: SonicFlow автоматически пробует резервный поток. Убедитесь в наличии активного интернет-соединения или используйте раздел "Local Files" для воспроизведения локальных аудиофайлов.

---

## 2. Проблемы с синхронизацией текста (Lyrics)

### Симптом: Текст песни не скроллится автоматически
- **Причина**: Пользователь недавно прокрутил текст вручную.
  - *Решение*: При ручной прокрутке автоскролл приостанавливается на 4 секунды, чтобы дать прочитать текст. Подождите 4 секунды или нажмите появившуюся кнопку "Следовать за музыкой".

### Симптом: Строка подсвечивается раньше или позже звука
- **Причина**: Несовпадение таймкодов в импортированном `.lrc` файле со студийной версией аудиозаписи.
  - *Решение*: Нажмите кнопку настроек текста и задайте смещение (Offset) в миллисекундах (`+500ms` / `-500ms`).

---

## 3. Проблемы с темами оформления

### Симптом: Ошибка валидации при импорте JSON темы
- **Причина**: Файл темы содержит неизвестные поля или значения цветов не в формате HEX / RGBA.
  - *Решение*: Убедитесь, что JSON соответствует схеме версии 1 (см. `THEMING_GUIDE.md`).
