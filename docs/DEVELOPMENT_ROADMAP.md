# SonicFlow — Дорожная карта разработки (Development Roadmap)

В данном документе зафиксированы этапы создания, цели, контрольные задачи, критерии приёмки и оценка рисков.

## Этап 0. Анализ и планирование
- **Цель**: Определение архитектуры, анализ ограничений SoundCloud API и платформ.
- **Задачи**:
  - Изучить ТЗ и визуальные референсы (Dark Studio, Synced Lyrics, Mobile Vinyl).
  - Сформировать матрицу технологического стека (React 18 + TS + Vite + Capacitor + Web Audio).
  - Проанализировать модель квот и ограничений стриминга.
  - Подготовить архитектурный каркас и документацию в каталоге `docs/`.
- **Критерии приёмки**:
  - Чётко определены контракты интерфейсов `AudioTrack`, `MusicProvider`, `LyricsSynchronizer`.
  - Задокументированы ограничения API и fallback-стратегия.
- **Риски**: Изменение доступности публичных эндпоинтов SoundCloud -> Решение: трехуровневый fallback (SoundCloud -> Legal open streaming catalog -> Local audio files).

## Этап 1. Инициализация проекта
- **Цель**: Создание запускаемой кодовой базы с линтингом, сборкой и типизацией.
- **Задачи**:
  - Настроить `package.json`, `tsconfig.json`, `vite.config.ts`.
  - Добавить переменные окружения в `.env.example`.
  - Настроить среду модульного тестирования Vitest.
  - Подготовить базовый `index.html` и точку входа `main.tsx`.
- **Критерии приёмки**:
  - Запуск `npm run dev` без ошибок.
  - Успешный запуск `npm test`.

## Этап 2. Дизайн-система (Dark Audio Studio)
- **Цель**: Полнофункциональная дизайн-система на CSS Custom Properties.
- **Задачи**:
  - Сформировать семантические токены цветов, типографики, скруглений, теней и отступов.
  - Создать базовые компоненты: кнопки, карточки альбомов, слайдер громкости и таймлайна, поля поиска, бейджи.
  - Обеспечить доступность по стандарту WCAG 2.2 AA (коэффициент контрастности не ниже 4.5:1).
- **Критерии приёмки**:
  - Все UI-элементы используют токены `:root`, отсутствие захардкоженных цветов.
  - Адаптивность для экранов от 375px (iPhone) до 2560px (Ultra-wide).

## Этап 3. Система тем
- **Цель**: Гибкая система стилизации с возможностью мгновенного переключения и визуального редактирования.
- **Задачи**:
  - Реализовать 9 встроенных тем: Midnight Black, SoundCloud Orange, Spotify Green, Ocean Blue, Violet Dream, AMOLED Pure Black, Light Minimal, Rose Neon, Custom Theme.
  - Разработать `ThemeManager` для применения темы к DOM без остановки воспроизведения.
  - Создать компонент `ThemeEditor` с колор-пикерами, слайдерами радиуса/плотности, интерактивным превью и экспортом/импортом JSON.
- **Критерии приёмки**:
  - Переключение тем происходит за < 16ms без мерцания и ререндера плеера.
  - Пользовательские темы валидируются и сохраняются в `localStorage`.

## Этап 4. Основной пользовательский интерфейс
- **Цель**: Трехколоночный десктопный интерфейс в точном соответствии с референсами.
- **Задачи**:
  - Левая панель: Меню (Главная, Альбомы, Локальные файлы, Избранное, Плейлисты), блок "Друзья" со статусами прослушивания.
  - Центральная зона: Шапка поиска с эквалайзером, Баннер артиста с неоновой подсветкой, карусель альбомов, топ треков, похожие исполнители.
  - Правая панель: Очередь воспроизведения (Play Queue) и интерактивный аудиоплеер с вращающимся винилом.
- **Критерии приёмки**:
  - Все ссылки и кнопки кликабельны и функциональны.
  - Плавная плашка изменения громкости и поиск.

## Этап 5. Музыкальный источник и провайдеры
- **Цель**: Получение и обработка метаданных и аудиопотоков.
- **Задачи**:
  - Реализовать интерфейс `MusicProvider`.
  - Реализовать `SoundCloudProvider` для поиска и метаданных.
  - Реализовать `LocalFileProvider` для перетаскивания и воспроизведения собственных MP3/WAV/FLAC файлов.
  - Подготовить встроенный каталог качественных стриминговых композиций.
- **Критерии приёмки**:
  - Работает поиск по названию и артисту.
  - Поддержка воспроизведения реального звука.

## Этап 6. Аудиодвижок и плеер
- **Цель**: Стабильное и точное воспроизведение аудио.
- **Задачи**:
  - Разработать `AudioEngine` с методами `play`, `pause`, `seek`, `setVolume`, `toggleMute`.
  - Подключить `AudioContext` и `AnalyserNode` для визуализации частот в реальном времени.
  - Поддержка режимов повтора (все/один/выкл) и случайного порядка (Shuffle).
  - Глобальные горячие клавиши (Space - пауза/плей, стрелки - громкость и перемотка).
- **Критерии приёмки**:
  - Плавный прогрессбар таймлайна с отображением прошедшего и оставшегося времени.
  - Автопереход к следующему треку в очереди по окончании.

## Этап 7. Синхронизированные тексты песен
- **Цель**: Экспириенс уровня Spotify / Яндекс Музыки.
- **Задачи**:
  - Разработать парсер LRC с миллисекундами `[mm:ss.xx]`.
  - Экран с вкладками: `Karaoke`, `Synced`, `Unsynced`, `Genius`.
  - Автоматический скролл к активной строке с центрированием.
  - Клик по строке перематывает воспроизведение на нужную секунду.
  - Кнопка импорта собственного `.lrc` или `.txt` файла.
- **Критерии приёмки**:
  - Строка подсвечивается точно в соответствии с позицией трека.
  - Ручной скролл временно отключает автоцентрирование.

## Этап 8. Библиотека и хранилище
- **Цель**: Персональное хранилище пользователя.
- **Задачи**:
  - Создание, удаление и редактирование плейлистов.
  - Добавление треков в избранное (лайк).
  - История последних прослушанных треков.
  - Надежное сохранение в LocalStorage / IndexedDB.
- **Критерии приёмки**:
  - Данные сохраняются после перезагрузки страницы или перезапуска приложения.

## Этап 9. Платформенная адаптация
- **Цель**: Кроссплатформенная готовность.
- **Задачи**:
  - Десктопная адаптация (Windows & Linux).
  - Мобильный интерфейс iPhone: виниловый диск в центре, динамический остров, всплывающая шторка текстов песен.
  - Поддержка `navigator.mediaSession` (управление на экране блокировки и с гарнитуры).
- **Критерии приёмки**:
  - Мобильный режим переключается и выглядит нативно.

## Этап 10. Тестирование и верификация
- **Цель**: Обеспечение стабильности и качества кода.
- **Задачи**:
  - Написание модульных тестов для LRC-парсера, ThemeManager, очереди и провайдеров.
  - Проверка сборки `npm run build` и типизации `tsc`.
- **Критерии приёмки**:
  - Все тесты проходят успешно (зелёные).

## Этап 11. Сборка и релиз
- **Цель**: Готовые конфигурации для сборки под целевые платформы.
- **Задачи**:
  - Сборка продакшн-дистрибутива.
  - Подготовка документации по установке и релизу.
- **Критерии приёмки**:
  - Артефакты сборки готовы к развертыванию.
