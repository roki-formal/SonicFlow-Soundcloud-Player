# SonicFlow — Дизайн-система (Design System)

Документ регламентирует визуальную систему SonicFlow: концепцию, цветовую модель, типографику, сетку отступов, скругления, интерактивные состояния и компоненты.

## 1. Концепция: Dark Audio Studio

Визуальный язык SonicFlow вдохновлен современными студийными аудиоинтерфейсами, темно-графитовой эстетикой Spotify и динамической выразительностью Яндекс Музыки.

### Ключевые принципы:
1. **Контент на первом плане**: Обложки альбомов и типографика треков выделяются на глубоком нейтральном фоне.
2. **Иерархия через контраст и вес**: Заголовки, вторичные подписи и метаданные визуально разделены без нагромождения разделительных линий.
3. **Плавная тактильность**: Плавные анимации наведения (180ms cubic-bezier), скругленные углы и мягкие светотени.
4. **Доступность (WCAG 2.2 AA)**: Коэффициент контрастности основного текста к фону не менее **4.5:1**, для акцентных заголовков и крупного текста — не менее **3:1**.

## 2. Цветовая модель и CSS-токены

Все цвета объявляются через семантические CSS Custom Properties:

```css
:root {
  color-scheme: dark;

  /* Базовые фоновые слои */
  --color-bg-base: #0a0a0d;           /* Корневой фон приложения */
  --color-bg-sidebar: #101015;        /* Фоновый цвет левой боковой панели */
  --color-bg-surface: #17171e;        /* Цвет карточек и плашек */
  --color-bg-surface-hover: #22222c;  /* Состояние hover для карточек */
  --color-bg-surface-active: #2b2b38; /* Активное/выбранное состояние */
  
  /* Панель плеера и модальные слои */
  --color-bg-player: #121218;         /* Фоновый цвет блока плеера */
  --color-bg-queue: #14141b;          /* Фоновый цвет очереди воспроизведения */
  --color-bg-overlay: rgba(0,0,0,0.7);/* Подложка диалогов и шторки */

  /* Типографика */
  --color-text-primary: #f8f8fa;      /* Основной читаемый текст (заголовки, треки) */
  --color-text-secondary: #a3a3b2;    /* Вторичный текст (артист, длительность) */
  --color-text-muted: #6e6e7e;        /* Приглушенные подписи, плейсхолдеры */
  --color-text-inverse: #0a0a0d;      /* Текст на светлом/акцентном фоне */

  /* Акцентные цвета */
  --color-accent: #ff5500;            /* Фирменный оранжевый акцент */
  --color-accent-hover: #ff7024;      /* Hover акцентной кнопки */
  --color-accent-subtle: rgba(255, 85, 0, 0.15); /* Фон бейджей и выделений */
  --color-accent-contrast: #ffffff;   /* Текст внутри акцентного элемента */

  /* Статусы */
  --color-success: #1db954;
  --color-warning: #ffa000;
  --color-error: #ff4343;

  /* Границы и разделители */
  --color-border: rgba(255, 255, 255, 0.08);
  --color-border-hover: rgba(255, 255, 255, 0.18);

  /* Тексты песен (Lyrics) */
  --color-lyrics-active: #ffffff;
  --color-lyrics-inactive: rgba(255, 255, 255, 0.35);
  --color-lyrics-hover: rgba(255, 255, 255, 0.7);
}
```

## 3. Сетка отступов и радиусы

- **Базовая единица (Spacing unit)**: 4px
  - `space-1`: 4px
  - `space-2`: 8px
  - `space-3`: 12px
  - `space-4`: 16px
  - `space-6`: 24px
  - `space-8`: 32px
  - `space-12`: 48px

- **Радиусы скругления (Border Radius)**:
  - `--radius-control`: 10px (кнопки, инпуты)
  - `--radius-card`: 16px (карточки альбомов, блок плеера)
  - `--radius-modal`: 24px (модальные окна, всплывающая шторка)
  - `--radius-pill`: 9999px (бейджи, переключатели)
  - `--radius-round`: 50% (аватары, кнопки Play)

## 4. Типографика

- Основной шрифт интерфейса: `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Inter, Helvetica, Arial, sans-serif`
- Акцентный винтажный шрифт для экрана плеера (в стиле референса 3): `Editorial Serif, "Playfair Display", Georgia, serif`

| Токен | Размер | Межстрочный | Начертание | Назначение |
|---|---|---|---|---|
| `font-hero` | 36px | 44px | Bold (700) | Главные заголовки артистов, мобильный плеер |
| `font-title` | 24px | 30px | Bold (700) | Заголовки секций (Albums, Popular) |
| `font-subtitle` | 18px | 24px | Semibold (600) | Названия альбомов, плейлисты |
| `font-body` | 14px | 20px | Regular (400) / Medium (500) | Названия треков, меню, кнопки |
| `font-caption` | 12px | 16px | Regular (400) | Метаданные, счетчики, таймкоды |

## 5. Компоненты дизайн-системы

1. **Кнопка воспроизведения (Play Button)**:
   - Десктопная панель: круглая кнопка 44x44px с акцентным цветом и иконкой треугольника/паузы.
   - Мобильный плеер: крупный круг 68x68px по центру с плавной анимацией масштабирования при нажатии (`active:scale-95`).
2. **Карточка альбома (Album Card)**:
   - Соотношение 1:1, скругление 14px, градиентная подложка при загрузке.
   - Эффект всплывающей кнопки воспроизведения при ховере на десктопе.
3. **Таймлайн (Progress Scrubber)**:
   - Высота дорожки 4px в покое, 6px при наведении.
   - Активный прогресс заливается акцентным цветом.
   - Интерактивный ползунок-бегунок диаметром 12px.
4. **Визуализатор аудио (Audio Visualizer)**:
   - 4-полосный анимированный эквалайзер в шапке поисковой строки, синхронизированный с Web Audio API.
5. **Вращающийся виниловый диск (Vinyl Disc)**:
   - Текстура виниловых канавок с бликом света, круглая этикетка по центру с обложкой трека.
   - Вращение со скоростью 33⅓ RPM при воспроизведении и плавная остановка при паузе.
