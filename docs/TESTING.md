# SonicFlow — Руководство по тестированию (Testing Guide)

Документ описывает структуру модульных тестов, стратегию валидации и команды запуска.

---

## 1. Стек тестирования

- **Фреймворк**: [Vitest](https://vitest.dev/) — быстрый современный тестовый раннер, нативно интегрированный с Vite.
- **Окружение**: `happy-dom` для быстрой имитации DOM и событий.

---

## 2. Структура тестов (`tests/`)

```text
tests/
├── lrc-parser.test.ts        # Тестирование парсера LRC, таймкодов и бинарного поиска
├── theme-manager.test.ts     # Тестирование реестра тем, валидации токенов и расчета контраста
├── playback-queue.test.ts    # Тестирование очереди, перемешивания Shuffle и режима Repeat
└── storage.test.ts           # Тестирование сохранения плейлистов и миграций
```

---

## 3. Команды запуска тестов

```bash
# Однократный прогон всех модульных тестов
npm test

# Запуск тестов в режиме отслеживания изменений (watch mode)
npm run test:watch
```

---

## 4. Критерии прохождения тестов (Acceptance Criteria)

- Парсер LRC должен корректно обрабатывать миллисекунды, мульти-таймкоды и игнорировать поврежденные строки.
- Вычисление коэффициента контрастности WCAG должно выдавать точные значения для крайних случаев (#000000 vs #ffffff -> 21:1).
- Очередь `PlaybackQueue` при включении `shuffle` должна гарантировать присутствие всех треков без дубликатов.
- Переключение тем должно валидировать JSON-схему и отбрасывать небезопасные значения.
