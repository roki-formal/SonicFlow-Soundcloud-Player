# Changelog

Все значимые изменения в проекте SonicFlow документируются в этом файле.
Формат соответствует [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).

## [1.2.0] - 2026-10-21

### Добавлено
- **Полноценный нативный мобильный плеер**:
  - Адаптивный мобильный шелл (`MobileShell`) с поддержкой всех разделов (Главная, Поиск, Лайки, Плейлисты, Очередь).
  - Закрепленный плавающий мини-плеер (`MobileMiniPlayer`) с микро-скраббером прогресса и кнопками управления.
  - Полноэкранный мобильный плеер (`MobileVinylPlayer`) с фотореалистичным вращающимся винилом, тактильным скраббером и шторкой синхронизированных караоке-текстов песен.
  - Учет системных безопасных зон iOS (Safe Area insets).
- **Готовое iOS приложение (.ipa)**:
  - Скомпилирован полноценный пакет `SonicFlow.ipa` с Mach-O бинарником, `Info.plist` и сгенерированными Capacitor ассетами.
  - Поддержка установки без Mac через AltStore, Sideloadly, TrollStore и Scarlet.
- **Готовый пакет для Arch Linux**:
  - Нативный пакет pacman `sonicflow-1.2.0-1-x86_64.pkg.tar.zst` для мгновенной установки через `sudo pacman -U`.
  - Официальный рецепт сборки `PKGBUILD` для Arch Linux и AUR.
  - Универсальный портативный Linux-архив `SonicFlow-Linux-x86_64.tar.gz` со скриптом установки `install.sh`.
- **Автоматизированный конвейер релизов**:
  - Скрипт `scripts/build-release.js` (`npm run build:release`) для одновременной сборки Windows, iOS и Linux релизов с генерацией `SHA256SUMS.txt`.
  - GitHub Actions workflow `.github/workflows/release.yml` для автоматической публикации релизов по пушу тегов `v*`.

### Изменено
- Переписан `README.md`: добавлена таблица загрузки готовых релизов и актуальная документация.
- С десктопной версии удалена кнопка переключения на демонстрационный мокап телефона — десктоп теперь работает как чистая профессиональная аудио-студия.
- Удалены все фиктивные демонстрационные профили, верхняя панель профиля в очереди воспроизведения теперь отображает реальный подключенный аккаунт SoundCloud с возможностью 1-клик авторизации.

## [1.0.0] - 2026-10-21

### Добавлено
- Инициализация проекта SonicFlow на стеке React 18 + TypeScript + Vite.
- Комплексная документация в каталоге `docs/`: архитектура, дизайн-система, темы, тексты песен, плеер, платформенная поддержка, сборка и тестирование.
- Дизайн-система **Dark Audio Studio** на CSS Custom Properties с поддержкой WCAG 2.2 AA контраста.
- 9 встроенных тем: Midnight Black, SoundCloud Orange, Spotify Green, Ocean Blue, Violet Dream, AMOLED Pure Black, Light Minimal, Rose Neon, Custom Theme.
- Визуальный редактор тем (Theme Editor) с настройкой акцентных цветов, радиусов, прозрачности, проверкой контрастности и JSON импортом/экспортом.
- Трехколоночный интерфейс по референсам:
  - Левая колонка: Навигация, Библиотека, Список друзей с активностью.
  - Центральная колонка: Поиск, Профиль артиста, Сетка альбомов, Популярные треки, Похожие исполнители, Локальные треки.
  - Правая колонка: Очередь воспроизведения (Play Queue) и мини-плеер с виниловой анимацией.
- Мобильная адаптация под iPhone (iOS) с Dynamic Island, виниловым диском и всплывающей шторкой текстов песен.
- Движок воспроизведения аудио `AudioEngine` на базе HTML5 Audio и Web Audio API с аудиоанализатором для визуализатора.
- Система синхронизированных текстов песен (`LyricsSystem`):
  - Полноценный LRC-парсер с миллисекундами.
  - Режимы `Synced`, `Karaoke`, `Unsynced`, `Genius`.
  - Автоматическая плавная прокрутка к активной строке.
  - Клик по строке для быстрой перемотки трека.
  - Возможность загрузки собственных `.lrc` и `.txt` файлов.
- Модуль музыкальных провайдеров (`MusicProvider`):
  - SoundCloud API интеграция с валидацией стримов и квот.
  - Fallback streaming провайдер с высококачественными аудиопотоками и метаданными.
  - Провайдер локальных аудиофайлов (`LocalFileProvider`).
- Модуль персональной библиотеки и хранилища (`StorageModule`):
  - Управление плейлистами (создание, переименование, удаление, сортировка).
  - Избранное (лайки) и история прослушиваний.
  - Сохранение пользовательских настроек и тем.
- Поддержка платформ:
  - Windows десктоп (.exe) и Linux (.AppImage, .deb).
  - iOS адаптация через Capacitor, поддержка MediaSession API (клавиши гарнитуры, экран блокировки, MPRIS).
- Набор модульных тестов на базе Vitest.
